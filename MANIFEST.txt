1. Open any page tx on an Ethereum explorer -> 'View Input As -> UTF-8' = the text.
2. Concatenate a document's pages in order.
3. Verify: sha256 each page -> Merkle tree (pairwise, duplicate last if odd) -> compare to Merkle root.
Each book also has a Beacon (human-readable description) and an Ethscription (data: URI catalog entry), listed per book above.
